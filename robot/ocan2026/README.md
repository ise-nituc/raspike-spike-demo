# 2026 オープンキャンパス用 RaspikeArt ライントレース

## ねらい

昨年度の教材と同じ `forward()`、`left()`、`right()`、`stop()`、
`black()`、`white()` を用意しています。参加者が編集するのは原則として
`app.c` の `tracer_task()` だけです。モーターやセンサーを初期化する処理は
`LineTracer` が隠すため、40 分の体験では「動いた」「条件で動きが変わった」
「線をたどれた」の三段階に集中できます。

## 機体ボタン制御（実装候補・実機未検証）

起動後はモーター停止で待機し、フォースセンサーの新しい押下ごとに
走行開始→一時停止→再開を切り替えます。起動時の押しっぱなしでは走りません。
解放と押下を各4回の安定サンプル（通常10ms間隔）で確認し、長押しでは反復切替しません。

固定のmain_taskがボタンと実モーター出力を担当し、学習用tracer_taskは指令を渡します。
一時停止では周期起動と学習タスクを終了し、古い起動要求と指令を捨てます。
再開は学習処理の先頭からで、変数の初期化やRestoreではありません。
PC・ブラウザ断だけでは停止せず、機体ボタンは通信と独立して監視します。
Web/CLIでの実行終了は既存機構を使います。

ホストテストは `bash robot/ocan2026/tests/run-host-tests.sh`。
[実機確認の補足とPR #20への修正案](button-control-hardware-check.md)を参照し、
学生の実機試験は教員の具体的な許可後に行ってください。
無限ループ時のプリエンプション、SDK API内の待ち、物理停止時間は未検証です。
この出力ゲートはforward等の教材APIを通る出力が対象で、直接のモーターAPIや
割込み禁止等を使う任意Cの隔離ではありません。

## 40 分の進行案

| 時間 | 内容 | `tracer_task()` に書くもの |
|---:|---|---|
| 0～5 分 | 光センサーと反射率を説明 | 完成済みプログラムを実演 |
| 5～12 分 | 前進・左右・停止を試す | `forward();` などを一つずつ |
| 12～22 分 | `if` 文を体験 | `if (black()) { stop(); } else { forward(); }` |
| 22～34 分 | ライントレースに挑戦 | 黒なら右、白なら左（逆なら左右を交換） |
| 34～38 分 | 発展または競走 | `smooth_trace();`、速度・係数の調整 |
| 38～40 分 | 振り返り | センサー→判断→モーターを確認 |

最初から空欄にせず、各段階で動作するコードを渡して一部分だけ変更させると、
入力ミスで時間を失いにくくなります。ペア作業なら「入力係」と「ロボット係」を
途中で交代させます。

## 講師の事前準備

1. 会場と同じ照明・コースで `brightness()` の白と黒の値を測ります。
2. `LineTracer/LineTracer.h` の `WHITE_BRIGHTNESS` と
   `BLACK_BRIGHTNESS` を実測値に変更します。
3. 全車両で左右のモーターとセンサーのポートを確認します。
4. 通常課題用（`if` 文）と救済・発展用（`smooth_trace()`）の完成ファイルを
   別途保存し、いつでも復元できるようにします。
5. コースアウトしても机から落ちないコースを用意し、書き込み時は車輪を
   浮かせます。

## ライントレースのコア

`black()` と `white()` は、白と黒の反射率の中間をしきい値にした二値判定です。
基本課題は判定結果に応じて左右へ曲がる「ON/OFF 制御」です。

**既知の制約:** 現状の`left/right`は`black/white`が更新する操舵値を使うため、
単独呼出しで必ず旋回するとは限りません。`smooth_trace`は宣言のみで実装が
コメントアウトされているため、上記の発展例は現状ビルドできません。
今回の変更はボタン制御に限定し、これらの教材APIは変更していません。

以下は想定されていた発展機能の説明です。`smooth_trace()` は、反射率と目標値（白黒の中間）との差に
`STEERING_COEF` を掛け、左右モーターの出力差にする比例制御です。差が大きいほど
強く曲がります。公式サンプルのコアを保ちつつ、一つの関数として呼べるように
しています。出力は安全のため -100～100 に制限しています。

### 調整の順番

1. 白・黒の反射率を先に合わせる。
2. `BASE_SPEED` を低めから上げる。
3. 直線でふらつくなら `STEERING_COEF` を下げ、カーブで外れるなら上げる。

複数の値を同時に変更させず、一回走るごとに一つだけ変えて結果を記録させると、
「制御を調整する」体験になります。
