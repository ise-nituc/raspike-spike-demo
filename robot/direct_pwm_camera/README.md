# direct_pwm_camera

TCPサーバーから左右モーターのPWM値を直接取得して走行するRasPike-ART用の
アプリケーションです。`line_trace_camera` とは独立しています。

カメラ黒線追従では `vision-server/vision_server_picamera.py` と組み合わせます。
旧 `robot/line_trace_camera/` は通信形式が異なります。マーカー追従には `marker_controller.py` を使います。

通常開発の正式手順は[学生向けガイド](../../docs/student-development-guide.md)、
完成デモの操作は[ルートREADME](../../README.md)を参照してください。
編集する正本はこのディレクトリです。SDK workspaceへコピーやリンクを作る必要はありません。

```bash
cd ~/raspike-spike-demo
./scripts/build-robot direct_pwm_camera
./scripts/start-robot direct_pwm_camera
```

名前指定の `start-robot` もビルド（またはキャッシュ復元）を行うため、通常は後者だけで十分です。
Pythonは先に別途起動します。ビルド失敗時は起動に進みません。古い `asp` が残り得るため、
引数なしの起動を通常手順に使わないでください。

## TCPプロトコル

- 接続先: `127.0.0.1:65432`
- クライアント要求: `GET <control_enabled> <emergency_stop> <applied_left> <applied_right> <r> <g> <b>\n`
- サーバー応答: `<left>:<right>:<stop_mode>:<reflection_threshold>:<r_min>:<r_max>:<g_min>:<g_max>:<b_min>:<b_max>\n`
現行Cはこの10項目応答に加え、旧3項目の `left:right:reflection_threshold\n` を受理します。
単純 `GET\n` に対する2項目の `left:right\n` 応答は受理しません。

- PWM値の範囲: `-100`～`100`
- RGB値の範囲: `0`～`1023`（カラーセンサーの10 bit生値）。`stop_mode` は0=無効、1=反射率、2=RGB範囲です。

受信値は安全のためRasPike-ART側でも `-100`～`100` に制限します。通信失敗を検出した場合と
一時停止時には左右のモーターを停止します。マーカー追従Web画面では、カラーセンサーによる
緊急停止を無効・反射率・RGB範囲から選べます。ライントレースではこの緊急停止を無効にします。
フォースセンサーと緊急停止の状態はPWM要求と一緒にサーバーへ通知され、Web画面に表示されます。
直前の制御周期でモーターAPIへ設定した左右PWMも通知されるため、Web画面でPython側の
計算PWMが走行体まで届いたか確認できます（エンコーダーによる実回転の検出ではありません）。
この拡張値を表示するには、変更後の `direct_pwm_camera` を再ビルドして走行体を再起動して
ください。旧バイナリとの通信自体は継続できますが、「ロボット適用PWM」は通信待ち表示になります。
`marker_controller.py` が返す値も現在は `-100`～`100` です。

## 操作

初期状態は一時停止です。フォースセンサーを押して離すと制御を開始し、次に押して離すと一時停止、
さらに押して離すと再開します。切替は解放後なので長押し中は切り替わりません。
起動時に押したままなら、その解放が開始操作として扱われます。解放後の新しい押下を必須にする将来仕様は未実装です。
モーターは
左がポートB、右がポートA、カラーセンサーがポートE、フォースセンサーがポートDです。

## 停止処理と未確認事項

Cは接続・送受信・応答解析の失敗を検出するとモーター停止処理を呼びます。
ただし受信はブロッキングで明示的な期限がなく、Python無応答で一定時間内に停止するとは保証できません。
Pythonの最新PWMにも画像鮮度で失効させる検査は確認できません。フォース操作も制御異常時まで
確実に効くと実証したものではなく、チャタリング対策や停止時間は実機確認が必要です。
ブラウザの切断だけでは自動停止しません。

終了は起動経路に合わせて、Webではロボットの「停止」、SSHでは前景ターミナルの `Ctrl+C` を使い、
続いてPythonを停止します。まずフォース操作で一時停止し、実際の車輪停止を確認してください。
WebのロボットunitはSIGKILLでプロセス群を終了するため、通常終了処理による実モーター停止とは区別します。
画面の状態や適用PWMは実回転・停止の証明ではありません。今回実機試験は行っておらず、
Ctrl+C・SIGKILL・通信断・無応答時の停止時間と物理停止手段は教員が実機で確認してください。
