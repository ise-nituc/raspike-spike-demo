CAMERA LINE TRACE

カメラで黒線を走ろう！

ロボットのカメラが床の黒い線を見つけます。線が曲がると、左右のタイヤの速さを変えてコースに沿って走ります。

黄色い枠の中から黒線を探し、緑の点をつないで進む方向を考えています。

黒線確認中…
ロボットの判断確認中…
左右のモーターL 0 / R 0

1見る

カメラの画像を明るさの数字に変えて、床と黒線を見分けます。

2考える

黒線の位置と向きから、まっすぐ・右・左のどちらへ進むか決めます。

3動かす

左右のタイヤを別々の速さで回します。急カーブでは速度も落とします。

走り方を調整する（スタッフ向け）

会場の明るさやコースに合わせる設定です。値を変えたら「設定を保存」を押してください。
